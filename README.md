# MORNING — Coffee Shop

## О проєкті

MORNING - адаптивний односторінковий сайт кав'ярні.
Проект створено у рамках фінальної практичної роботи з верстки.

На сайті представлені:
- інформація про кав'ярню;
- популярні напої та десерти;
- інформація про переваги кав'ярні;
- адаптивна навігація;
- кнопки для переходу за розділами сайту;
- Адаптивна версія для мобільних пристроїв.

## Використані технології

- HTML5
- SCSS
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts
- Git / GitHub

## Особливості реалізації

### SCSS

Для стилізації веб-сайту вживається SCSS.

У проекті використовуються:
- змінні для кольорів та основних розмірів;
- Вкладеність SCSS;
- окремі файли стилів для різних блоків;
- медіазапити для адаптивності.
